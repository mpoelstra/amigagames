# A Shard of Hope — narrative and rhythm variations

User prefers A Shard of Hope but requests a happier peaceful first plate,
darker middle, hopeful ending, and more rhythmic/tempo variety. These three
original derivatives begin in G major, turn to E minor/Am/B7 for Archivolt and
the storm, then return to a major resolution. Lead phrases remain connected.

- IV Morning Sparks: lilting bass groove, light percussion; scene tempos
  132 / 128 / 120 / 130 / 132 BPM, about 60.12 seconds.
- V Clockwork Dawn: syncopated bass and kick responses; scene tempos
  150 / 132 / 150 / 132 / 150 BPM, about 60.21 seconds.
- VI Skybound: strongest backbeat, driving eighth-note bass in storm/finale;
  scene tempos 150 / 150 / 164 / 150 / 172 BPM, about 60.84 seconds.

Tempo changes are real ProTracker Fxx events. MP3s render the actual four-channel
MODs using micromod; no external backing layers or time stretching. MOD hashes,
scene tempo events, duration, unclipped pre-master PCM and MP3 decoding checked.
No assistant aural approval is claimed. Exact scene sync remains approximate
because intro disk loads and user skip/advance change runtime timing. Intro cues
are not integrated. Previous tracks, title build and sole game test are preserved.
