# Copper Sprint

Original Level-1 action accompaniment: 164 BPM, 32 bars, ~46.81-second loop.
Three voices: drums with combined hat attacks, pulse bass and syncopated synth
motifs/stabs. The third eight-bar section changes texture without slowing tempo.
Fourth track entirely empty. No external melodies, reference audio or samples.

The short synthesized instruments total 11,552 bytes. MOD is 20,828 bytes.
Generator + MOD + manifest are the reproducible authoring source; previews are
ignored outputs. Requires NumPy and a host C compiler for pinned micromod.
Micromod previews are listening aids, not proof of native ptplayer behaviour.
See ../../../../experiments/audio-level1/README.md from the repository's Sparkpaw
root, or sparkpaw/experiments/audio-level1/README.md in repository-root notation.

The combined preview reproduces the actual C mixer's event sequence offline.
It is intentionally hard stereo: effects on Paula 3's left side. Native output
filtering, exact gains/timing and subjective acceptance need the user test.
