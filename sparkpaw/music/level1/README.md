# Level 1 — Copper Sprint

Original 164 BPM, three-voice track accepted in the Level-1 audio proof.
This MOD is byte-identical to ../experiments/level1-pulse/copper-sprint.mod;
the composer generator, manifest and research previews remain there.
Channel four is completely empty, including effect commands. The main HD
build splits the unchanged MOD into a 9276-byte Fast score and 11552-byte
Chip sample bank using tools/prepare_game_audio.py. No fixed-50-Hz conversion.
