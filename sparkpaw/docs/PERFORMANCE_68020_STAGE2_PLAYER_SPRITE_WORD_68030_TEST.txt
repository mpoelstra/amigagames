Sparkpaw Stage 2 player-sprite cache word conversion: FS-UAE/68030 gate

Purpose
-------
This candidate replaces only the CHARGING-time pixel conversion of Sparkpaw's
hardware-sprite cache with masked planar word transfers. The 48px artwork stays
inside the same transparent-padded 64px attached pair on channels 0/1. Runtime
staging, control words, animation selection and all accepted graphics remain
unchanged. Both earlier accepted word-copy optimizations are active.

Test
----
Run Sparkpaw-Player-Sprite-Cache-Word with the normal FS-UAE/68030 setup. Check
Sparkpaw facing left and right, idle, run, jump, crouch, shoot, turn, hurt and
ledge poses where practical. Inspect the transparent right padding, tail, feet
and detached components. Also verify enemies, HUD and the ground seam. Exit with
the left mouse button and leave renderdiag.log here.

Acceptance boundary
-------------------
This is an FS-UAE/68030 diagnostic presentation gate. It is not production,
68020, ADF, Pocket or real-hardware acceptance.
