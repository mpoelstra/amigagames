## Five dedicated intro sources, 27 August 2026

The current integrated proof uses the five `*-aga-polish.png` sources. Each was
redrawn with `assets/concept/sparkpaw-title-concept.png` as the authoritative
reference for premium AGA pixel clusters, value range and cyan/orange/violet
colour hierarchy. Prompts preserve the 5:4 canvas, upper art window and empty
lower reading band, while simplifying microdetail for 320x168 reduction.

Plate 3 was then rejected because its deterministic circular overlay read as
pasted-on UI. The accepted replacement was generated completely from scratch,
using only the title as style reference. It uses a much wider valley view and
five identical recessed crystal-shaped niches integrated into the central
Stormstone façade in a 1-2-2 arrangement; no overlay is applied by conversion.

Built-in ImageGen generated four dedicated 1402x1122 source plates to accompany
the accepted Balance source: Archivolt and the damaged instruction, exactly
five elemental Cores, Sparkpaw's visibly combined detector/toaster, and the
departure toward the archive. Every prompt required a landscape PAL layout,
an empty lower reading band, hard late-era AGA pixel clusters, no generated
story text and direct continuity with the project-owned title/gameplay art.
The deterministic intro generator crops the upper composition, supplies its
own reading band and bitmap font, reduces each complete plate to 64 colours and
writes one six-plane SPBM. These generated sources remain concept-quality art;
in particular Archivolt's exact arm count and workshop Sparkpaw scale require
later native-resolution polish before production acceptance.

## Stormkeeper's Waystation, 25 August 2026

Built-in ImageGen was asked for a new 320x208 side-view late-era Amiga AGA pixel
art scene: a quiet Storm Ruins clearing; one attractive stone-and-steel
caretaker cottage/shrine about half a screen wide; a crooked storm-bent pine
growing through its roof; cyan conduits, dark doorway and a single large cyan
Stormstone Core floating above a pedestal; no player, HUD, enemies, platforms,
text or extra crystals. The composition required a clear left approach, the
waystation/tree on the right and the established navy/violet/cyan/pale-stone
world identity.

The composition result is
`assets/stormkeeper-waystation-concept-v1.png`. A second generation requested
the same building/tree/Core cluster as an isolated orthographic hard-edged
pixel-art cutout with no scenery or actors. Its checker-backed RGB result is
preserved as `sparkpaw/assets/concept/sparkpaw-stormkeeper-waystation-source-v1.png`;
the runtime generator explicitly keys the neutral checker before palette
mapping. Neither generated bitmap is itself hardware-ready runtime art.
